# 台本管理

台本ブラッシュアップ時は、最初に [`現行統合台本.md`](./現行統合台本.md) を確認してください。現在の画面に出る本編、スタッフロール、NOVACENEを安定ID付きで一冊にまとめています。

## ファイルの役割

- `現行統合台本.md`: 現行表示の統合レビュー版。`npm run story:export`で実行データから生成します。
- `台本修正版_2026-08-23.md`: ユーザー承認済みの本編271本文とNOVACENE 3シーン／53メッセージを保持する現行入力です。
- `物語台本.md`: 本編6シーンの凍結入力。これだけでは現行表示と一致しません。
- `observation-log-revisions-20260822.js`: 凍結入力へ適用する現行差し替え。本文・話者ラベル・演出メタデータを含みます。
- `../novel-story-data.js`: 凍結入力と差し替えを土台に、承認済み入力のID順と本文を適用して生成される本編ランタイム。直接編集しません。
- `../true-end-data.js`: 承認済み入力から生成されるNOVACENE 3シーンのランタイム台本。直接編集しません。
- `../novel-mode.js`: 本編最終行からスタッフロール、さらにNOVACENEへ接続する処理とクレジット本文。
- `../contest-limited/story/機能限定版台本.md`: `物語台本.md`と同一の保持コピー。統合レビュー版ではありません。

## ブラッシュアップ手順

1. `現行統合台本.md`で対象IDを確認する。
2. 修正内容をID単位で決める。
3. 現行本文の修正は`台本修正版_2026-08-23.md`へ反映する。凍結入力と旧差し替えJSは互換メタデータの土台として維持する。
4. `npm run data:novel`で本編とNOVACENEのランタイムを生成し、`npm run story:export`を実行する。
5. `npm run check`で統合台本とランタイムが一致することを確認する。

統合台本へ直接書いた案は、自動的には製品表示へ入りません。実装ソースへ反映せず統合台本だけが変わった場合、`npm run check`が不一致として停止します。これにより「読んでいる台本と現在のシナリオが違う」状態を検出します。
