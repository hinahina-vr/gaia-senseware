# 場面仕様｜production_year 背景境界

## 結論

`production_year`は一つの場所ではない。現在の展示席、三人それぞれの遠隔制作画面、海に近い町の共同作業室、駅・電車・中古機材店などを行き来する。scene全体へ`production-night-v2`を固定しない。

本文・step ID・日時は変更せず、背景だけを次の境界で切り替える。

## 最低限必要な切替点

1. scene開始前：`production_year_001`から展示席`exhibition-v3`。
2. 最初の回想：`_006`のtransition中に切替、`_007`から遠隔制作。
3. 十一秒の現在挿入：`_150`から展示席、`_156`から遠隔制作へ戻す。
4. 初めて同じ机：`_175`から共同作業室`production-shared-meeting-v3`、`_195`表示前に終了。
5. 友人テスト：`_200`から共同作業室、`_215`表示前に終了。
6. scene終端の現在復帰：`_259`から展示席。

## 誤配置を防ぐ条件

- `_001`で`production-night-v2`を出さない。ここは現在の展示席である。
- `_007`〜`_167`の遠隔制作を、三人が夜の同じ共用室にいる場面として描かない。
- `_150`〜`_155`と`_259`〜`_261`は過去の制作室ではなく、現在の展示席である。
- `_168`で共同作業室へ先行せず、本文で入室する`_175`から切り替える。
- `_195`の帰りの電車以後に、共同作業室背景を残さない。
- `_248`〜`_258`は予約・相談であり、実際の次回集合は次sceneの不在場面である。

`novel-bg-production-shared-meeting-v3.png`は20・30側から共有された採用素材名であり、この10担当worktreeでは背景mappingや素材ファイルを変更しない。
