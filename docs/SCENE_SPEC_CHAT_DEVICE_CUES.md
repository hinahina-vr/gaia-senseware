# 場面仕様｜学内チャットの端末cue

## 判定基準

- `mobile`：屋外、移動中、または本文でスマートフォン操作が明示される区間。学内チャットはスマートフォンの縦長画面として見せる。
- `wide`：共同作業室、各自の制作画面、または現在の展示端末で開く区間。学内チャットは展示端末・PCの横長画面として見せる。
- 三人が別々の場所から投稿する場面を、一つの物理空間として描かない。`wide`は全員が同じ部屋にいるという意味ではない。
- 投稿に添付された写真の場所と、投稿を読んでいる人物の場所を混同しない。
- scene全体へ一つの端末属性を付けず、下表の境界stepで切り替える。日時metadataはこの仕様へ追加しない。

## 20・35・60への確定事項

- `first_meeting_hall`は、chatを含む`_021`〜`_023`と`_042`〜`_048`を`mobile`とする。scene全体へ一律指定しても現行本文上は大きな矛盾を作らないが、必要範囲は上記二区間だけである。
- `absence`はscene単位指定を禁止する。少なくとも`_040 mobile`→`_041 wide`、`_061`〜`_063 mobile`の切替が必要である。
- `prologue_basil`と`production_year_125`〜`_127`の園芸売り場は投稿写真である。アマネとサクヤを売り場の現実空間へ配置しない。
- `mode10_space_030`は`type=chat`でも、現在の展示端末に保存済みの受信文を表示するため`wide`とする。
- 学内チャット内の小型avatarと、右下の大型立ち絵解禁ゲートは別制御である。
