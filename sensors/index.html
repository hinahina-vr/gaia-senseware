    コードを書いたことがなくても大丈夫です。上から順に進めてください。最初は実センサーなしでも、ESP32がつくるテスト値で接続を確認できます。

    PREPARE

    用意するもの

    • ESP32 / ESP32-S3一般的な開発ボードでOK
    • USBデータケーブル充電専用ケーブルは不可
    • Windows / MacArduino IDEを書き込めるPC
    • 2.4GHz Wi-FiSSIDとパスワードを確認
    1. 01
      Arduino IDEをPCへ入れる

      Arduino公式サイトからArduino IDE 2をインストールして起動します。

    2. 02
      ESP32とArduinoJsonを追加する

      Arduino IDEの「ファイル → 基本設定 → 追加のボードマネージャのURL」に次のURLを貼ります。

      https://espressif.github.io/arduino-esp32/package_esp32_index.json

      次に左側のボードマネージャで「esp32」を検索し、esp32 by Espressif Systemsをインストールします。左側のライブラリマネージャでは「ArduinoJson」を検索し、ArduinoJson 7.xをインストールします。

    3. 03
      スターターコード3ファイルを保存する

      下の3つをダウンロードし、PCに SmartCitySensorDemo というフォルダを作って、3ファイルともその中へ移動します。ファイル名は変えません。

      1 / MAINSmartCitySensorDemo.ino2 / CONFIGconfig.h3 / HTTPSroot_ca.h

      コードの中身はまだ変更しなくてOK。最初はテスト用の温度・湿度・PM2.5が自動で送られます。

    4. 04
      ESP32へ書き込む

      SmartCitySensorDemo.inoをArduino IDEで開き、ESP32をUSBでPCへつなぎます。「ツール → ボード」で自分の機種を選び、分からなければESP32 Dev Moduleを選択。「ツール → ポート」で新しく現れたCOM/USBポートを選び、左上の→（アップロード）を押します。

      「Connecting...」で止まる場合は、ESP32のBOOTボタンを押したままアップロードし、書き込みが始まったら離してください。ポートが出ない場合は、別のUSBケーブルを試します。

    5. 05
      このWebでPairing Codeを発行する

      書き込みが終わったらESP32はUSBにつないだままにします。参加方法を選び、「マイセンサー → センサーを追加」で名前と地域を登録すると、9文字のPairing Codeが表示されます。

    6. 06
      ESP32へWi-Fiとコードを教える

      PCまたはスマホのWi-Fi設定から CITY-SENSOR-XXXX を選びます。「インターネットなし」は正常です。その接続のままブラウザで http://192.168.4.1/ を開き、2.4GHz Wi-Fi名・Wi-Fiパスワード・Pairing Codeを入力して「接続して登録」を押します。

    7. 07
      ONLINEを確認して完了

      ESP32が再起動したら、PC・スマホを普段のWi-Fiへ戻します。約1分後に「マイセンサー」を開き、ONLINEと測定値が見えれば登録完了です。

    IF IT STOPS

    うまくいかないとき

    CITY-SENSOR-XXXX が見つからない

    ESP32をUSBから抜いて挿し直し、30秒待ちます。それでも出なければBOOTボタンを5秒長押しすると、保存済み設定を消して設定用Wi-Fiへ戻ります。

    192.168.4.1 が開かない

    PC・スマホが普段のWi-Fiへ自動で戻っていないか確認し、CITY-SENSOR-XXXXへ再接続します。モバイル通信を一時的にOFFにすると開きやすくなります。

    Pairing Codeが期限切れになった

    Pairing Codeは10分・1回限りです。「マイセンサー」で未接続の端末を削除し、「センサーを追加」から新しいコードを発行してください。

    登録したのにOFFLINEのまま

    2.4GHz Wi-FiのSSIDとパスワードを確認します。5GHz専用Wi-Fiには接続できません。Serial Monitorを115200 baudで開くと、秘密情報を表示せず接続状態だけ確認できます。
