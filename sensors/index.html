    WHAT IS FIRMWARE?

    ファームウェアとは？

    ESP32はPCのような固定OSへ後からアプリを追加する機器ではありません。FreeRTOS、ESP-IDF／Arduinoの処理、Wi-Fi・HTTPS通信、GAIAアプリをひとまとめにしたファームウェアをフラッシュへ書き込み、その全体で動きます。そのため、書き込み前には現在の4MB全体をバックアップします。

    1. 01
      USBで機種と保護状態を確認

      ESP32をデータ対応USBケーブルでPCへ接続します。チップ、revision、フラッシュ容量、Secure Boot、フラッシュ暗号化を確認します。不一致や保護機能が見つかった場合は書き込み前に止めます。

    2. 02
      現在のフラッシュを丸ごと保存

      4MB全体を読み出し、ファイルサイズとSHA-256を確認して保管します。元のファームウェアへ戻すときに必要です。バックアップ完了前は消去・書き込みをしません。

    3. 03
      検証済みGAIAファームウェアを書き込む

      Codexへ下の依頼文を送り、対応確認・バックアップ・SHA-256確認・書き込み・起動確認をまとめて依頼します。

      このESP32をGAIA SENSEWAREへ登録して。対応確認→全容量バックアップ→SHA-256確認→検証済みファームウェア書き込み→USB設定の順で進め、秘密は会話やログへ表示しないで。
    4. 04
      公開観測点とPairing Codeを作る

      名前・メールなしでおためし、またはGoogle連携で参加します。「マイセンサー → センサーを追加」で名前・地域・約10km単位の公開位置を指定するとPairing Codeが発行されます。

    5. 05
      Wi-Fi情報とコードをUSBで渡す

      Codexの案内で2.4GHz Wi-Fi情報とPairing CodeをUSBからESP32へ設定します。Wi-Fi情報はESP32内に保存され、GAIAのサーバーへは送信しません。USBが使えない場合のみ、設定用Wi-Fi CITY-SENSOR-XXXX と 192.168.4.1 を使います。

    6. 06
      ONLINEを確認してUSBを外す

      「マイセンサー」でONLINEと観測値を確認します。以後はESP32へ電源を供給すれば、PCを常時つながなくてもWi-Fi経由でHTTPS送信します。

    IF IT STOPS

    うまくいかないとき

    CITY-SENSOR-XXXX が見つからない

    ESP32をUSBから抜いて挿し直し、30秒待ちます。それでも出なければBOOTボタンを5秒長押しすると、保存済み設定を消して設定用Wi-Fiへ戻ります。

    192.168.4.1 が開かない

    PC・スマホが普段のWi-Fiへ自動で戻っていないか確認し、CITY-SENSOR-XXXXへ再接続します。モバイル通信を一時的にOFFにすると開きやすくなります。

    Pairing Codeが期限切れになった

    Pairing Codeは10分・1回限りです。「マイセンサー」で未接続の端末を削除し、「センサーを追加」から新しいコードを発行してください。

    登録したのにOFFLINEのまま

    2.4GHz Wi-FiのSSIDとパスワードを確認します。5GHz専用Wi-Fiには接続できません。Serial Monitorを115200 baudで開くと、秘密情報を表示せず接続状態だけ確認できます。

    PARTICIPATION TERMS / SAFETY

    利用条件と、
    書き込み前の注意。

    安全に参加するための実務上の条件です。登録を始める前に確認してください。

    PUBLIC

    登録内容は公開されます

    すべての登録センサーは「みんなのセンサー」に表示されます。センサー名、観測値、国・地域、約10km単位に丸めた位置が公開対象です。正確な住所、GPS座標、Wi-Fi情報、Device Tokenは公開しません。

    OWNERSHIP

    自分が管理できる機器と回線を使う

    所有者または管理者から許可を得たESP32、USB接続PC、2.4GHz Wi-Fiだけを使ってください。施設・学校・職場など第三者のネットワークでは、その管理規則に従ってください。

    BACKUP

    上書き前に全フラッシュを保存する

    ファームウェア書き込みは現在の内容を上書きします。容量全体のバックアップ、ファイルサイズ、SHA-256を確認し、復元手順と一緒に保管してください。ただし機器差、故障、保護設定により復元を保証できない場合があります。

    STOP

    不一致や保護機能があれば止める

    対応機種・フラッシュ容量が違う、Secure Boot／フラッシュ暗号化が有効、既存機能を失う影響が不明、書き込みエラーが続く場合は、消去や再試行を重ねず停止してください。

    SECRETS

    秘密情報を表示・共有しない

    Wi-Fiパスワード、Device Token、セッションCookieは会話、画面共有、ログ、Gitへ出さないでください。Wi-Fi情報はESP32内へ保存されます。物理的に機器へ触れられる人による読み出しリスクも考慮してください。

    NON-CRITICAL

    展示・教育・試作用途です

    生命、安全、医療、防災、設備制御、法定監視、事業継続など、停止や誤差が重大な損害につながる用途には使わないでください。通信、サービス継続、観測値の正確性を保証するものではありません。

    DATA

    データの扱い

    実測値と模擬値を混同しないでください。おためし参加中も「マイセンサー」から名称・地域・公開位置を修正し、端末を削除できます。8時間以内に「Google登録してセンサーを引き継ぐ」を選ぶと、同じセンサー・Device Token・観測履歴をGoogleアカウントへ保持します。引き継がずにログアウトすると、おためし利用で登録したセンサーと観測データを削除します。Google参加後も端末を削除すると、そのTokenでの送信を停止できます。
